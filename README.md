# 拯救外星人 · BLACKSITE 09

一款竖屏、科幻监狱主题的 Meta 网页游戏。外星人知道自己是游戏角色，会对玩家点击、谜题挑战和越狱行为作出反馈。

## 在线游玩

**[点击开始游戏：https://diaosang.github.io/rescue-alien-meta-game/](https://diaosang.github.io/rescue-alien-meta-game/)**

也可以将该链接生成二维码，在手机微信中扫码打开。

## 本地运行

下载仓库中的 `index.html`，使用现代浏览器（Chrome、Edge、Safari 等）打开即可。游戏是单文件网页，不需要安装依赖。
