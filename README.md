# 逃出存档室 · Meta Game

这是一个可直接部署到 GitHub Pages 的单文件网页游戏。打开 `index.html` 即可本地游玩。主题是“拯救外星人”：玩家进入一间会吐槽的监狱牢房，完成更高难度的三项解谜。

## 已实现的关键词逻辑

- **角色与玩家区分**：玩家通过点击操作；外星人有独立的视觉形象、对话气泡和状态。
- **第四墙互动**：外星人知道自己在游戏中，会评论点击行为，并在失败时把失败“存档”。
- **反抗玩法框架**：电脑小游戏叫“反抗协议”，门、存档、倒计时和失败反馈都被角色拿来嘲讽。
- **多周目影响**：周目、已完成小游戏、嘲讽历史和前周目选择保存到 `localStorage`；下一周目房间文案会显示记忆已被改写。
- **主循环**：监控终端、牢门衣柜、证物箱、脚印地毯四个热点中任选三个完成限时小游戏，收集三把钥匙后开门；所有空白区域也会触发吐槽。
- **1000 句不重复嘲讽**：使用“主语 × 动作”组合生成 36 句以上基础变体，并记录已展示内容；同一存档中不会重复，持续扩展到 1000 条。

## GitHub Pages 部署

1. 新建 GitHub 仓库，把 `index.html` 和 `README.md` 上传到仓库根目录。
2. 在 **Settings → Pages** 中选择 `Deploy from a branch`、`main`、`/ (root)` 并保存。
3. 打开 Pages 给出的地址，点击游戏里的“生成扫码入口”。二维码会指向当前网页地址。

二维码使用 `api.qrserver.com` 动态生成，因此首次打开分享弹窗需要网络连接。
